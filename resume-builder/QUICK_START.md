# Quick Start Guide - AI-Powered Resume Builder

Get up and running with the Resume Builder in 5 minutes!

## Installation (2 minutes)

```bash
# 1. Navigate to project directory
cd resume-builder

# 2. Install dependencies
pnpm install

# 3. Start development server
pnpm run dev

# 4. Open in browser
# Visit: http://localhost:3000
```

## Your First Resume (3 minutes)

### Step 1: Enter Your Information
1. In the left sidebar, fill in your name, email, phone, and location
2. Write a brief professional summary (or use AI assistant)

### Step 2: Add Your Experience
1. Click the "+" button next to "Work Experience"
2. Fill in: Company, Position, Dates, and Description
3. Add as many positions as needed

### Step 3: Add Education
1. Click the "+" button next to "Education"
2. Fill in: School, Degree, Field, Graduation Date
3. Add all your educational background

### Step 4: Add Skills
1. Type a skill in the "Add skill..." field
2. Press Enter or click "+"
3. Add all relevant skills

### Step 5: Customize Design
1. **Choose Template**: Select from 12 professional templates
2. **Adjust Colors**: Pick primary and secondary colors
3. **Fine-tune Typography**: Adjust font size, line height, margins
4. **Select Font**: Choose from Inter, Geist, Georgia, or Courier New

### Step 6: Export Your Resume
1. Click **"Export PDF"** to download as PDF (best for email/printing)
2. Or click **"Export JPEG"** to save as image (best for social media)

## Using the AI Assistant

1. Click the floating **chat bubble** in the bottom-right corner
2. Describe your role or experience (e.g., "Senior Software Engineer with 5 years experience")
3. The AI generates a professional summary
4. Click **"Use This"** to apply it to your resume

## Tips for Best Results

### Professional Summary
- Keep it concise (2-3 sentences)
- Highlight key achievements
- Use action words
- Match job description keywords

### Work Experience
- Use bullet points or short paragraphs
- Quantify achievements (e.g., "Increased sales by 25%")
- Include relevant technologies or tools
- Focus on impact, not just duties

### Skills
- List only relevant skills
- Prioritize by importance
- Include technical and soft skills
- Organize by category if needed

### Design
- Choose a template that matches your industry
- Use professional colors (avoid neon/bright colors)
- Ensure good contrast for readability
- Keep margins consistent

## Common Tasks

### Switch Templates
1. Go to "Design Settings" section
2. Select a different template from the dropdown
3. Your data is preserved automatically

### Change Colors
1. Find "Primary Color" or "Secondary Color"
2. Click the color picker or enter hex code
3. Changes apply instantly to preview

### Adjust Font Size
1. Use the "Font Size" slider (10-16px)
2. Drag to increase or decrease
3. Preview updates in real-time

### Add More Sections
- Work Experience: Click "+" button
- Education: Click "+" button
- Skills: Type and press Enter

### Remove Items
- Click the trash icon next to any item
- Confirm deletion
- Item is removed from resume

## Troubleshooting

### Resume not updating?
- Refresh the page (Ctrl+R)
- Check browser console (F12)
- Clear browser cache

### Export not working?
- Ensure all required fields are filled
- Check browser permissions
- Try a different browser

### Colors not showing?
- Verify hex code format (#RRGGBB)
- Clear browser cache
- Refresh the page

### AI Assistant not responding?
- Check internet connection
- Refresh the page
- Try a different browser
